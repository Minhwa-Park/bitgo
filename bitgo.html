    알림 설정 방법 (GitHub Actions + ntfy 푸시)

    1. 휴대폰에 ntfy 앱을 설치합니다. (안드로이드: Play 스토어 또는 F-Droid, 아이폰: App Store)
    2. 남이 짐작하기 어려운 주제 이름을 만듭니다. 예: bitgo- 뒤에 랜덤 16자. 이 이름이 사실상 비밀번호이므로 남에게 알려 주지 마세요.
    3. ntfy 앱의 + 버튼으로 그 주제 이름을 구독합니다. (서버는 기본값 ntfy.sh)
    4. GitHub 저장소 Settings → Secrets and variables → Actions에 NTFY_TOPIC 이름으로 주제 이름을 등록합니다.
    5. Actions 탭 → wonyotti-alert → Run workflow에서 테스트를 체크하고 실행하면 휴대폰으로 테스트 알림이 옵니다.
    6. 이후 10분마다 자동으로 1시간봉을 분석하고, 롱 우위 또는 숏 우위로 바뀔 때만 푸시 알림을 보냅니다. 만료되는 토큰이 없어서 따로 갱신할 일은 없습니다.

    이 알림은 이 화면을 열어 두지 않아도 GitHub가 대신 실행합니다. 참고용 시뮬레이션이며 투자 권유가 아닙니다.

    워뇨띠 매매 원칙 요약과 이 분석의 규칙 보기

    알려진 원칙 (커뮤니티가 정리한 Q&A 기준, 본인 확인 불가)
    · 캔들과 거래량을 가장 신뢰하고, 보조지표는 참고만. 이평선은 기본 설정으로 추세 확인 때만 봄
    · 정해진 매매법은 없다고 말함. 스캘핑 위주이며 일봉 시나리오는 짜지 않음
    · 잘 아는 패턴이 나올 때만 진입, 거래량은 예측의 신뢰도로 사용
    · 분할 진입·분할 청산, 아는 구간이 끝나면 바로 청산
    · 손절은 대략 3~5%, 격리 포지션으로 시드 일부만 운용, 이익의 20%는 바로 출금

    이 화면의 점수 규칙
    · 20봉 고점 돌파 +2 / 20봉 저점 이탈 −2 (잘 아는 패턴)
    · 최근 확정 3봉 연속 양봉 +1 / 음봉 −1
    · 직전 봉 장대양봉 +1 / 장대음봉 −1, 긴 아랫꼬리 +1 / 긴 윗꼬리 −1
    · 가격 > 20이평 > 60이평 +1 / 반대 −1
    · 상위 봉(15분→1시간, 1시간→4시간, 4시간→일봉)이 20이평 위 +1 / 아래 −1
    · 합계 +3 이상이고 거래량이 평균 이상이면 "롱 우위", −3 이하면 "숏 우위", 그 외는 "관망"

    워뇨띠 본인의 실제 포지션이나 판단이 아니며, 투자 권유가 아닙니다. 실제 매매에 그대로 쓰지 마세요.
